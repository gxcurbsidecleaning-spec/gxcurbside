# GX Curbside Cleaning

Vite + React + Tailwind starter for the GX Curbside Cleaning landing page.

Quick start

```bash
npm install
npm run dev
```

Build

```bash
npm run build
npm run preview
```

Files of interest:
- `src/components/TrashCleaningWebsite.jsx` — main UI component
- `src/App.jsx` — app entry
- `index.html` — app mount
